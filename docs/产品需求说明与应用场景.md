## 一、产品定位

**SpideHarness Agent** — 开源免费的热点新闻信息抓取与智能整理 Agent CLI 工具，基于 Harness Engineering 架构，零成本对标万元级舆情 SaaS。

### 核心能力

| 能力 | 说明 |
|------|------|
| **开源免费** | CLI + 12 数据源 + AI 分析，零门槛本地部署 |
| **12 数据源聚合** | 5 热搜 API（微博/百度/抖音/知乎/B站）+ 7 深度采集平台（小红书/抖音/快手/B站/微博/贴吧/知乎） |
| **AI 原生** | LLM 驱动摘要/情感/趋势/策略分析，非简单关键词匹配 |
| **MCP 协议** | 可接入 Claude/GPT 等任意 MCP 兼容模型 |
| **CLI Agent** | 可嵌入 CI/CD、定时任务、数据管道 |

### 竞品对比

| 定位 | 代表产品 | 定价 | SpideHarness 差异化 |
|------|----------|------|---------------------|
| **企业舆情 SaaS** | 识微商情、鹰眼速读网、拓尔思 TRS | 年费万元级 | **开源 CLI Agent**，零门槛，本地部署 |
| **开源聚合** | TrendRadar、GitHubDaily | 免费 | 多 **7 平台深度采集 + AI 分析** |
| **数据采集工具** | Bright Data、Firecrawl | 按量付费 | 面向**中文社媒热点场景**深度优化 |
| **新媒体管理** | 新榜、云探 | 月费千元级 | 提供 **MCP 协议**，可接入任意 AI 模型 |

### 典型应用场景

**场景 1：自媒体热点追踪**
> 自媒体创作者需要在第一时间发现全网热点，生成选题灵感。
> - 输入：`spide crawl -a` 一键采集 5 大平台热搜
> - AI：`spide analyze -s weibo --strategy` 分析趋势 + 生成内容策略
> - 输出：热点脉络 + 创作角度建议

**场景 2：品牌舆情监控**
> 品牌市场团队需要监控品牌提及量、情感倾向、竞品动态。
> - 输入：`spide schedule start -d 3600` 开启 1 小时定时监控
> - 分析：`spide analyze -k "品牌名,竞品"` 关键词情感分析
> - 导出：`spide export -f excel` 生成 Excel 报表

**场景 3：危机公关响应**
> 公关团队需要在舆情发酵初期发现负面苗头，快速响应。
> - 监控：关键词告警 + 情感阈值触发通知
> - 深度：`spide deep-crawl -p xhs -k "负面词"` 抓取原帖内容
> - 分析：`spide analyze` 情感倾向 + 传播路径

**场景 4：行业研究报告**
> 分析师需要批量采集数据，生成行业报告。
> - 批量：`spide batch-crawl -p xhs,dy,bili -k "AI"` 多平台并行采集
> - 导出：`spide export -f json` 结构化数据输出
> - 可视化：`spide wordcloud` 生成词云 + `spide analyze` 趋势分析

**场景 5：开发者数据管道**
> 开发者将 SpideHarness 嵌入自有系统，作为数据源。
> - MCP：`spide mcp-serve` 暴露 5 个工具给 AI 模型调用
> - MQTT：通过 EMQX Cloud 订阅实时推送
> - 存储：`spider storage/` 模块直接复用 SQLite + Redis

| 类型 | 平台 | 采集方式 | 数据维度 |
